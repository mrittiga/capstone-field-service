# Capstone - Work Order Management System

## Backend Documentation

A Spring Boot REST API for managing work orders, technician assignments, parts inventory, and SLA tracking.

### Quick Start

#### Prerequisites
- Java 21+
- Maven 3.9+
- PostgreSQL 15+

#### Setup Database

```bash
# Create database
createdb capstone_db

# Or using psql
psql -U postgres -c "CREATE DATABASE capstone_db;"
